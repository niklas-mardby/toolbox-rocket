# 🧩 Lösningar

Här finns en lösning till varje övning. Strukturen speglar [`/exercises`](../exercises/): samma mappar och samma projekt, men med koden färdig.

- 📝 **Varje lösning har en `NOTES.md`** med resonemanget bakom lösningen och **alternativa sätt** att lösa uppgiften. Det finns nästan alltid mer än ett bra svar.
- 🧪 **Alla tester är påslagna** (`Todo.Skip = null`), och några lösningar har *extra* tester, till exempel bonusuppgifternas.
- 🔑 **Facit till frågorna** (reflektionsfrågor, scenarier och matchningar) finns i [`/answers`](../answers/).

```bash
# Kör alla lösningars tester
dotnet test

# Eller en enskild lösning
dotnet test solutions/01-refactor/shipping-cost-calculator/ShippingCostCalculator.Tests
```

> 💡 Jämför med din egen lösning. Skiljer de sig åt? Det är inte säkert att din är sämre. Läs `NOTES.md` och fundera över avvägningarna.
